# Nuxt Minimal Starter

Look at the [Nuxt documentation](https://nuxt.com/docs/getting-started/introduction) to learn more.

## 🚀 Project Overview

A dashboard for managing events, allowing users to add, edit, delete, and view events with support for file uploads and filtering.

### Prerequisites

- Node.js (v22.12.0)
- NPM
- Nuxt 3
- Pinia
- Tailwind CSS

### Installation & Setup

```bash
git clone https://github.com/MariamSherif185/CAT-task.git
cd CAT-task
npm install
npm run dev

```

### Features

Login/Register/logout

Event CRUD (Create, Read, Update, Delete)

Modal-based UI for forms

File upload support

Filtering with query params (e.g. expire_at[date-from])
